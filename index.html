Accessibility

Reduced motion swaps the graduation cinematic for a still crossing and turns continuous zooms and rotations into single cuts. UI text size scales the sidebar, log and menus — the world itself is untouched.

Privacy

When on, the game sends anonymous play events (moves, clicks, crafting, fights, menus) to the game's server so we can see which parts of the game are fun and which need work. No chat text, no personal data; tied to your account only if you're logged in.

Community

Sprites and sounds the community's Workshop has adopted quietly replace the placeholder/default art in your own game — a shared coat of paint, no download or install. Turn it off to play with the stock art only. Your own submitted-and-adopted proposals always show for you regardless of this setting.

Our RPG Workshop

The room this game is built in — players generate the art, write the quests, tune the world, and ship it to everyone. No coding or drawing skill needed: votes, names and ideas count as much as sprites. Same account as the game. Open the Workshop ↗
